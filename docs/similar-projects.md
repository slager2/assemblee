## 10 уроков для assemblee

1. **Источник материала важнее модели.** Рабочие схемы: своё видео + транскрипт (Opus, FunClip, HIVE) или сток-ВИДЕО по ключевым словам (MoneyPrinterTurbo, short-video-maker). Перейти с картинок на видео (Pexels Videos API / Pixabay / Coverr, бесплатно по ключу): движение в кадре убирает ощущение слайд-шоу сильнее любого эффекта.
2. **Голос — каркас ролика.** В «фактовых» проектах первым делаются сценарий и озвучка (Kokoro на CPU, Edge-TTS бесплатно), длительность сцен берётся из аудио. Нарезать кадры под реальные тайминги слов TTS, а не наоборот.
3. **Пословные караоке-субтитры — главный «вау»-элемент.** Whisper (whisper.cpp / faster-whisper) даёт тайминги слов; крупный жирный шрифт с подсветкой активного слова — стандарт Submagic/Opus/MPT. Дёшево (CPU), эффект большой. Делать детерминированным шаблоном, не решением модели.
4. **Модель выбирает, шаблон исполняет.** LLM даёт тему сцены, 2–4 поисковых слова, настроение. Остальное (клип 2–4 с, кроп 9:16 «cover», переходы, зум, громкость музыки, позиция субтитров) — фиксированный пресет. Это уже наша философия; усилить: меньше свободы модели в эффектах.
5. **Поиск клипа = ключевые слова + проверка зрением.** У Opus 4 из 11 B-roll не по контексту. Наш плюс — vision-модель: брать 5–8 кандидатов по ключевым словам, смотреть 1–3 кадра превью, выбирать лучший и отбрасывать неподходящие; это лучше случайного выбора у MPT.
6. **Структура: hook в первые 1–3 с и чистая концовка.** По HIVE без выбора границы hook rate падает с 0.71 до 0.28; пользователи Opus жалуются на обрывистые концовки. Зафиксировать каркас: hook (≤3 с, вопрос/цифра) → 3–5 пунктов → концовка/CTA, 20–40 с; модель заполняет слоты.
7. **Кормить модель текстом, а не пикселями; кэшировать описания.** LAVE, NarratoAI и HIVE сначала превращают медиа в текстовые описания, потом рассуждает LLM. У нас каталог по mtime уже есть — распространить на видео: описание по 1–3 кадрам на клип, кэш на диск.
8. **Малые локальные модели жизнеспособны на узких решениях.** Eddie AI дообучил Qwen3.5-9B до 47% побед против модели в 300 раз больше (предварительно); HIVE использует Qwen2-VL для слияния шотов. Подходит: выбор из enum, оценка «да/нет» по рубрике, ключевые слова, подпись кадра. Не подходит: длинное свободное планирование. Строгая JSON-схема (у нас есть) — правильный путь.
9. **Автомат даёт «черновик 70–90%», и это нормально.** Отзывы по Opus и MPT сходятся: нужна человеческая проверка. Добавить «3 варианта по одной теме» и «заменить этот клип» одним действием (как в LAVE), вместо погони за идеалом с первого раза.
10. **Единые шаблоны вместо «эффектов по ситуации».** Пресеты Remotion/MoviePy (стиль субтитров, вход/выход кадра, Ken Burns для оставшихся фото) дают единообразный вид. Фото + зум и SDXL — запасной вариант; AI-видео (Wan и др.) на 6 ГБ GPU нереалистично для массового использования, годится как редкая вставка.

## Какие источники материала дают хороший вид

| Источник | Вердикт |
|---|---|
| Сток-видео (Pexels/Pixabay/Coverr API) | лучший бесплатный вариант для «безлицевых» роликов; нужны точный поиск и vision-проверка |
| Своё видео + транскрипт | лучший результат (Opus, HIVE), но нужны исходники |
| Стоковые фото + Ken Burns | «слайд-шоу» — наш текущий проблемный режим; оставить как fallback |
| AI-картинки (SDXL) + зум | допустимо, единый стиль, но «ИИ-вид» |
| AI-видео (Wan, Seedance) | красиво, но дорого/долго, не на 6 ГБ |
